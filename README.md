## Publishing

The GitHub repository is `RoyceGames/roycegames.github.io`. Publish `main` from the repository root with GitHub Pages, set the custom domain to `roycegames.online`, and point Alibaba Cloud DNS to the GitHub Pages addresses shown in GitHub's current documentation. Keep the existing GitHub domain-verification TXT record. Enable HTTPS when available.

## Game release check

The website discloses the advertising providers supplied by the publisher, but the website cannot verify a game binary. Before linking a released game to this policy, check its installed SDKs and actual data flows; configure an EEA/UK consent flow and applicable U.S. state opt-out handling; pass choices to every advertising partner; implement ATT before iOS tracking or IDFA access; and align App Store privacy labels and Google Play Data safety answers. Confirm the support mailbox is monitored. Update the policy if the ad stack, products, legal publisher identity, or data practices change.

No advertising or analytics scripts are installed on this website. Do not add `app-ads.txt` until actual publisher IDs are known.
